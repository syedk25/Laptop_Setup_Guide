
# How to install ( .deb ) files

1. open terminal inside where the downloaded .deb file exist, ( by righ click  in empty space)
2. type
   ```Shell
   ls
   ```

3) copy ( cntrl+shift+c ) the file name
4) type

   ```Shell
   sudo apt install <file-name>
   ```
5) replace the <file-name.> with copied name by ( cntrl + shift + v)
